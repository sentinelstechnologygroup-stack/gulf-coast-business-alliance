# Gulf Coast Business Alliance

Public review site for Gulf Coast Business Alliance.

GCBA is a private, for-profit business alliance, member directory, referral network, lead-generation platform, sponsorship platform, and local service visibility system.

## Stack

- Vite
- React
- Tailwind CSS

## Local Development

Run npm install, then npm run dev.

## Production Build

Run npm run build.

## Review Status

This site is currently a review build. Some dashboard, member, lead, category, testimonial, and content-management areas may contain demo or placeholder data pending chair review, backend hardening, and final legal review.
